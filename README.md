# Encontra Leads

Ferramenta gratuita de prospecção local. Ela abre a pesquisa no Google Maps, organiza os contatos que você seleciona e gera mensagens personalizadas para revisão e envio manual.

## Rodar localmente

```bash
npm install
npm run dev
```

## Deploy na Vercel

Importe este repositório na Vercel. Não há variáveis de ambiente, banco de dados ou API paga para configurar.

Os leads ficam salvos somente no navegador de quem utiliza a ferramenta.
